# البوابة الإعلامية للبرامج الإلكترونية — أكاديمية الجيل الصاعد

- `docs/` الموقع المنشور (GitHub Pages). لا تعدّله يدوياً: يُبنى من `src/`.
- `src/` المصادر: المحرك والقوالب والواجهة، و`Code.gs` (الخادم على Apps Script)، و`build.py`.
- `assets/` الخطوط والشعارات والصور كما تُضمَّن في الموقع (بلا فقد في الجودة).

البناء:

```
python3 src/build.py
```

حزم القوالب الأسبوعية تبقى في درايف (مجلد «٢- حزم القوالب») ويقرؤها الموقع عبر الخادم.

## الإصدار السادس — منصة الأثر الإعلامي

- `v6/` الواجهة الجديدة (المحرر، لوحة الإدارة، البرامج، اصنع إعلانك). المرجع في `v6/DESIGN.md`.
- `src/Code.gs` خادم الإصدار السادس (يخدم الإصدار الخامس أيضاً)، ويُبنى إلى `server/Code.gs`:

```
python3 v6/build_gs.py
```

- بناء الواجهة في `docs/v6/` (معاينة) ونسخة تجربة محلية في `dist6/`:

```
python3 v6/build6.py
```

- `v6/app/` تطبيق الجوال (PWA) → يُبنى في `docs/app/` مع الواجهة. الرابط: https://ghamine23.github.io/media-portal/app/
- خط «ثمانية» لا يُرفع إلى المستودع: يُرفع من لوحة الإدارة فيُحفظ في درايف.
