# الإصدار السادس — مرجع العمل (يُحدَّث مع كل خطوة)

## قرارات المستخدم (٢٢ أكتوبر ٢٠٢٦)
- الاسم: «منصة الأثر الإعلامي» + شعار بخط ثمانية (كلمة مكتوبة بأسلوب 3bdullahux: كشيدة).
- الهوية: مثل https://3bdullahux.framer.ai بالضبط: أبيض/#f7f7f7، نص #000/#171717، رمادي #5e5e5e #707070 #999 #d6d6d6،
  عناوين Thmanyah Serif Display Medium (40px)، نص Thmanyah Serif Text Regular 18px / Light 16px، أزرار حبة سوداء،
  بطاقات بيضاء حواف 20–28px على خلفية #f7f7f7، مربعات أيقونات بألوان باستيل شفافة 10%،
  حركة: العناوين تظهر كلمة كلمة من ضبابية (blur→0) وشفافية، والبطاقات تتجمع، هادئة.
- الدخول: اسم مستخدم أو بريد + كلمة مرور، لا تسجيل ذاتي. أدوار: super / sup (مشرف برنامج) / user.
- أصول البرامج (شعارات، خطوط، صور) تُحمَّل بعد الدخول حسب الصلاحية — لا أصول في المستودع العام.
- المحرر: Konva لطبقة التفاعل بعد تجربة تطابق بالبكسل. الحركة هادئة.
- العناوين العامة باهتة + تنبيه عند التنزيل، ومعرض بأمثلة واقعية.
- المساعد: مجاني فقط (Gemini API free tier: gemini-3.8-flash)، وهو «اصنع إعلانك». خيار مواقع التواصل مخفي إلا لمشرف البرنامج ومن يُمنح الصلاحية.
- المهمة الأسبوعية: تشخّص البلاغات وتقترح، والتنفيذ بعد اعتماده.
- رفع خطوط من المستخدم، ومن المشرف/المدير للمنصة. رفع صور وعناصر وحفظها.
- لوحة إدارة كبيرة تفصيلية شاملة.
- التراخيص التجارية مقبولة إن كانت مجانية.
- بعد الانتهاء: تحويل «الصفحة التفاعلية قبل التنفيذ» إلى مهارة (propose_skills).

## ملاحظات ترخيص
- خط ثمانية: الاستخدام التجاري والمواقع والتطبيقات مسموح، ويُمنع رفع الملفات أو استضافتها للتنزيل أو تعديلها.
  القرار: لا تُرفع للمستودع العام أبداً، وتُخدم من درايف عبر الخادم كما هي (OTF بلا تحويل). يُبلَّغ المستخدم ويُنصح بتأكيد ذلك مع ثمانية.
- Gemini المجاني: البيانات تُستخدم لتحسين منتجات جوجل → لا تُرسل بيانات شخصية للطلاب.

## البنية
- `src/` محرك القوالب والقوالب (مشترك بين v5 و v6) + واجهة v5 (حية حتى الإطلاق).
- `v6/` الواجهة الجديدة → تُبنى في `docs/v6/` للمعاينة، ثم في `docs/` عند الإطلاق.
- `src/Code.gs` الخادم الواحد للنسختين (متوافق للخلف). `v6/gas/` محاكي خدمات جوجل لتشغيل Code.gs في Node وفي المتصفح (وضع التجربة).

## نموذج البيانات (في «٤- بيانات الموقع»)
accounts.json, programs.json, assets.json (+ مجلد assets), fonts.json (+ مجلد fonts), feedback.json, stats_YYYY-MM.json,
broadcasts.json, changelog.json, settings.json, audit.json. وتبقى users.json/index.json/i_*.json (v5) مع ربط الحسابات القديمة legacyKey.
